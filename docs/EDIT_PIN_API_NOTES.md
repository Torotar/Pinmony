# 已收藏 Pin 编辑

> 2026-10-03 传输调整：现有业务 API 脚本在注入时适配原生 RCP，接口参数、数据优先级、业务成功校验和禁止自动回退规则继续沿用本文；网站自身请求、认证探测与标题 HTML 读取仍由 Web 执行。原生凭据仅运行时读取，失败不自动重放。范围、手动传输回退及验收边界见 [原生网络说明](NATIVE_NETWORK_NOTES.md)。


入口来自当前网页三点菜单的“编辑 Pin 图”，未出现该菜单项时不自行提供入口。PIN_EDIT_API_ENABLED 为独立手动撤回开关，与帖子接口开关同时启用。失败不自动转旧 DOM 操作。

读取 PinResource 当前会话用户及 Pin pinner，再调用 编辑pin.har 确认的 GraphQL b275f25a...，同时校验 entityId 和 pinner.entityId。仅允许当前账号保存的 Pin，GraphQL 编码 id 不作为写入 ID。原生界面按用户补充截图显示图片、Pin 图标题、描述、所属图板、AI 修改开关和删除入口；标题与描述从当前 PinResource 读取，空值也显示输入框，内容区域可滚动。

图板选择复用 BoardPickerBoardsResource 及创建图板面板。编辑流程排除仅供 Repin 无 board_id 使用的个人资料伪图板；选择图板后返回编辑，完成时用 PinResource/update/ 提交标题和描述草稿（支持清空及多行描述），保留未修改的 AI 元数据，同一图板保留原分区，换图板清空分区。不使用 RepinResource 创建另一条收藏。输入仅更新当前编辑会话的内存草稿，不逐字发送网络请求；完成时同时传入最终草稿，避免轮询或最后一次输入同步影响提交。修改后的标题/描述必须与保存响应一致，否则显示结果未确认且不自动重放。

删除需明确确认后才提交当前自有 Pin ID 到 PinResource/delete/，运行时 trackingParams 加 ~0。code、endpoint 与保存响应 Pin/图板/AI 数据校验后才结束面板并通知结果；删除成功返回上一页，清除该详情缓存。资料 API 重置，返回图板时其路由切换重新加载。

写入锁阻止重复请求及关闭面板；异常结果不自动重放，需要重新读取后检查实际状态。仅静态及离线回归/HAP 构建验证，账号在线编辑和删除尚未执行。

关闭 PIN_EDIT_API_ENABLED 并重建可将编辑菜单恢复为未接入状态。接入前源文件在 backups/edit-pin-before-20261001，restore.ps1 默认核验，-Apply 恢复已有文件，拒绝后续修改。Index 快照恢复会恢复完整文件，应先检查其间其他功能的修改；优先用独立开关。
