# 运行日志导出

设置页“导出运行日志”通过系统 DocumentViewPicker 保存 TXT；取消不提示成功，保存失败显示重试提示。运行时摘要最多保留最近 1000 条、每条最多 800 字符写入应用内部文件；完整会话记录另存并在重启时保留上一段。

记录生命周期、原生页面/加载故障、返回及提示条关闭/撤销，收藏请求与业务校验成功。网页控制台只接收四种固定收藏诊断事件，不保存任意网页输出、接口正文、请求头或会话存储；原生日志过滤 URL、凭据字段及长数字身份标识。

这不是完整系统 HiLog、原生崩溃栈或 HAR。诊断日志不改变收藏、撤销、返回逻辑，不能据此宣称设备故障已修复。关闭提示条和点击撤销分别记录。

验证：scripts/check-runtime-log.cjs（传 DevEco TypeScript 路径）检查过滤、重启保留、容量、取消及导出。HAP 编译与设备导出/异常退出后的留存需分开报告。
