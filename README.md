<h1 align="center">Pinmony</h1>

Pinmony 是个人出于兴趣开发的 HarmonyOS 应用，用于学习、技术研究与移动端体验探索。账号登录使用 ArkWeb，登录后的业务界面使用 ArkUI 原生呈现。部分功能依赖当前登录会话及 Pinterest 网站内部同源资源，这些资源不是 Pinterest 官方开放 API。本项目与 Pinterest 及其关联方不存在隶属、合作或授权关系。

Pinmony is a personal-interest HarmonyOS app for learning, technical research, and exploring mobile experiences. Sign-in uses ArkWeb, while screens after sign-in use native ArkUI. Some features rely on the active login session and Pinterest's internal same-origin resources, which are not official public APIs. This project is not affiliated with, partnered with, or authorized by Pinterest or its affiliates.
